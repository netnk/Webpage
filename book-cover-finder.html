書封網址查詢工具

以書名（可含作者、出版社）查詢 Google Books / Open Library，取得封面圖片網址。全部在瀏覽器內執行，進度自動存檔，可中斷續跑。

1. 載入資料

支援 CSV / TXT（每行一筆）。Excel 請先另存為「CSV UTF-8」。也可直接貼上：
欄位對應：

2. 設定

每本書最壞情況會發出 2～4 次 API 請求，2 萬筆請預留足夠的 API 額度。額度用完（連續 429）時，工具會自動暫停並存檔，隔天再按「繼續」即可。

3. 執行
